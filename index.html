Linear integration
How this dashboard connects to your Linear workspace
Setup steps
1. Create free Linear workspace at linear.app
2. One team "Engineering", 6 projects — one per roadmap month
3. Settings → Integrations → GitHub → Connect (auto-closes issues from commits)
4. Get API key: Settings → API → Create key
5. Run python sync.py locally to push/pull between this dashboard's export and Linear

Full guide: docs/linear_setup_guide.md in your repo
