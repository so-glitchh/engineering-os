How Data Persistence Works
No backend needed. All data lives in your browser's localStorage under key mehfooj_eng_os_v2. Every action (adding a target, toggling a checkbox, writing a journal entry) calls save() which serializes the entire state to JSON and writes it to localStorage.

Cross-device sync: Export state.json → commit to GitHub → clone on new device → import. Your GitHub repo is the single source of truth across machines.

Daily updates: Dates are computed from new Date() on each page load. Journal entries, daily checks, and streak data are all keyed by ISO date string (YYYY-MM-DD).
